# 高考数学 · 上世纪旧卷排版改善（1952—1999）

**范围已根据要求修正**：2025 年和 2026 年的原始 PDF 排版保留，不再做统一重排；2000 年及以后的现有试卷也不纳入本次自动构建。2025/2026 年此前生成的试验性 typeset PDF/TeX 已从 main 撤下，仍可从 Git 历史恢复。

## 哪些卷会改变？

- 原始 papers/ 中的 775 份试卷 PDF **永远保留不覆盖**，其中 2025 年 6 份、2026 年 6 份维持原样。
- 主要针对 1952—1999 年现有档案中版面不佳的旧卷。该区间有 37 个收录年份、167 份固定来源 TeX，**并非断言这 167 份都有排版问题**。
- 工作流可以按年生成排版候选（1999 年向前），但候选版本不直接替换原版；只有逐页对照发现原版确实较差、题目和插图又完整时才建议采用。
- 2000—2026 年源文件在 full-source-archive 中原样保存，但选年脚本、独立构建器与 GitHub Actions 均拒绝再次生成这些年份的新排版。

## 上世纪旧卷的排版方案

基于已固定版本的完整中文 TeX 和原图，不通过 OCR 猜公式。采用 XeLaTeX、A4、Fandol 中文宋体、TeX Gyre 数学字体，统一题号、标题、适度页边距、公式间距及分页。按年份先编译，然后用 PDF 的章节书签严格拆分独立卷；每卷 PDF 和含正文的 TeX 成对保留。

技术检查包括：源文件与插图存在、题目环境数量、XeLaTeX 正常编译、PDF 页数与完整性、中文字可检索、中文字体嵌入、无真实缺字、按章拆分页码无遗漏。通过上述技术检查不等于视觉复核或数学正确性已经全部通过。

## 自动化与复核

GitHub Actions 现行工作流：XeLaTeX typeset historical Gaokao maths (1952-1999)。每 30 分钟检查一次待生成的上世纪候选年份，也可以手动指定 1952—1999 的年份。失败年份写入 blocked/，暂时跳过，保留日志以待修复。编译结果的 visual_review 仍为 pending 时不代表已经优于原试卷。

1952 年全国卷已作为初始技术样例保存在 typeset/papers/1952/；其他旧卷优先进行原版与候选版的实际页面对比。正式的原卷仍以 papers/ 对应条目为准。
