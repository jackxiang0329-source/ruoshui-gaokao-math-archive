## 已确认不同，绝不误删或误合并

- **2012-shandong-common**：[2012-shandong_science-q22](https://github.com/DxAThing/Gaokao-Math-Problems-Compilation/blob/f1ae169b58a75b3db6e35c670b3f0d5c78718188/content/2012/shandong_science.tex#L751) 与 [2012-shandong_liberal-q22](https://github.com/DxAThing/Gaokao-Math-Problems-Compilation/blob/f1ae169b58a75b3db6e35c670b3f0d5c78718188/content/2012/shandong_liberal.tex#L446)。前两问相近，但文科第三问定义 g(x)=x f'(x)，理科第三问定义 g(x)=(x²+x) f'(x)，因此不是相同题目

- **2011-shaanxi-function-common**：[2011-shaanxi_science-q23](https://github.com/DxAThing/Gaokao-Math-Problems-Compilation/blob/f1ae169b58a75b3db6e35c670b3f0d5c78718188/content/2011/shaanxi_science.tex#L605) 与 [2011-shaanxi_liberal-q23](https://github.com/DxAThing/Gaokao-Math-Problems-Compilation/blob/f1ae169b58a75b3db6e35c670b3f0d5c78718188/content/2011/shaanxi_liberal.tex#L642)。文理卷前两问虽然都研究 $g(x)=\ln x+1/x$，但理科第三问是「是否存在 $x_0$ 使 $|g(x)-g(x_0)|<1/2$ 对所有 $x>0$ 成立」（否：$g(x)\to\infty$），文科第三问是求 $g(a)-g(x)<1/a$ 对所有 $x>0$ 成立的参数范围（$0<a<e$）。不可因前两问相似而合并。

- **2012-shaanxi-common**：[2012-shaanxi_science-q23](https://github.com/DxAThing/Gaokao-Math-Problems-Compilation/blob/f1ae169b58a75b3db6e35c670b3f0d5c78718188/content/2012/shaanxi_science.tex#L584) 与 [2012-shaanxi_liberal-q23](https://github.com/DxAThing/Gaokao-Math-Problems-Compilation/blob/f1ae169b58a75b3db6e35c670b3f0d5c78718188/content/2012/shaanxi_liberal.tex#L410)。共有首问，但理科第三问研究零点数列单调性，文科另考查偶数 $n$ 下 $b+3c$ 最值；不可合并。
- **2014-hubei-common**：[2014-hubei_science-q22](https://github.com/DxAThing/Gaokao-Math-Problems-Compilation/blob/f1ae169b58a75b3db6e35c670b3f0d5c78718188/content/2014/hubei_science.tex#L586) 与 [2014-hubei_liberal-q21](https://github.com/DxAThing/Gaokao-Math-Problems-Compilation/blob/f1ae169b58a75b3db6e35c670b3f0d5c78718188/content/2014/hubei_liberal.tex#L493)。共有函数与极值比较，但理科第三问额外要求六个数完整排序并证明，文科仅要求最大数和最小数；不可合并。

- **2013-sichuan-common**：[2013-sichuan_science-q21](https://github.com/DxAThing/Gaokao-Math-Problems-Compilation/blob/f1ae169b58a75b3db6e35c670b3f0d5c78718188/content/2013/sichuan_science.tex#L595) 与 [2013-sichuan_liberal-q21](https://github.com/DxAThing/Gaokao-Math-Problems-Compilation/blob/f1ae169b58a75b3db6e35c670b3f0d5c78718188/content/2013/sichuan_liberal.tex#L484)。理科第二问要求证明最小值可达 $1$，文科仅证明 $x_2-x_1\ge1$；题目要求不完全相同。
- **2014-sichuan-common**：[2014-sichuan_science-q21](https://github.com/DxAThing/Gaokao-Math-Problems-Compilation/blob/f1ae169b58a75b3db6e35c670b3f0d5c78718188/content/2014/sichuan_science.tex#L840) 与 [2014-sichuan_liberal-q21](https://github.com/DxAThing/Gaokao-Math-Problems-Compilation/blob/f1ae169b58a75b3db6e35c670b3f0d5c78718188/content/2014/sichuan_liberal.tex#L442)。理科第二问要求完整参数范围（必要与充分），文科只要求证明必要不等式 $e-2<a<1$；题目要求不完全相同。

- **2012-beijing-derivative-variant**：[2012-beijing_science-q18](https://github.com/DxAThing/Gaokao-Math-Problems-Compilation/blob/f1ae169b58a75b3db6e35c670b3f0d5c78718188/content/2012/beijing_science.tex#L482) 与 [2012-beijing_liberal-q18](https://github.com/DxAThing/Gaokao-Math-Problems-Compilation/blob/f1ae169b58a75b3db6e35c670b3f0d5c78718188/content/2012/beijing_liberal.tex#L378)。首问虽相同，但第二问分别为 $a^2=4b$ 下单调性与最大值、$a=3,b=-9$ 下参数区间 $k$ 的确定。 
- **2016-national1-derivative-variant**：[2016-national_paper_1_science-q21](https://github.com/DxAThing/Gaokao-Math-Problems-Compilation/blob/f1ae169b58a75b3db6e35c670b3f0d5c78718188/content/2016/national_paper_1_science.tex#L633) 与 [2016-national_paper_1_liberal-q21](https://github.com/DxAThing/Gaokao-Math-Problems-Compilation/blob/f1ae169b58a75b3db6e35c670b3f0d5c78718188/content/2016/national_paper_1_liberal.tex#L400)。理科另证两零点位置关系 $x_1+x_2<2$，文科则要求按参数分类单调区间；非同一道完整题。
