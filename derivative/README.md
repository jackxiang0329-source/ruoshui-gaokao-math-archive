# 高中导数大题

本目录用于已完成严格质检的逐题归档。**原始来源不能自动视为数学正确**。

| 分类目录 | 含义 |
|---|---|
| monotonicity | 单调性 |
| extrema | 极值与最值 |
| parameters | 含参函数与参数分类讨论 |
| inequalities | 恒成立及不等式证明 |
| implicit-roots | 隐零点 |
| double-roots | 双零点 |
| construct-functions | 构造函数与辅助函数 |
| roots-count | 零点个数与交点问题 |

每题应独立保存原题出处、年份卷种、`.tex`、`.md`、答案与独立复核记录，逐步输出统一 PDF。
