## 后续导入要求

1. 只从固定提交的 Git 对象读取原始字节，不能以网络搜索得到的同名 PDF 替换。
2. 将四份文件按原样写入 `mirror/gaokaomath/` 下的对应路径；PDF 严禁文字化或重新保存后冒充原始镜像。
3. 导入后逐个计算 `git hash-object <文件>`，并与上表 SHA 精确匹配；再检查文件字节数和 PDF 头标记。
4. 仅在四项均匹配时，将缺口状态改为“已验证”，重新生成 `mirror/MIRROR_STATUS.json`、`mirror/STATUS.md` 中的统计，并更新总表。
5. 完整镜像的校验应继续执行 `scripts/verify_pinned_mirror.py`；数学答案、试题真实性及第三方版权仍属独立审核范围。
